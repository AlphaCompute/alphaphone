## Backend evidence

`scripts/maps/prepare-region.py` downloads the dated Geofabrik `monaco-260929.osm.pbf`, Planetiler 0.10.2 and GraphHopper 10.2 into `~/.local/share/alphaphone-maps/monaco`. It builds actual OpenMapTiles vector data; the current output is 23 tiles / 409,600 bytes. The same extract feeds a 2,936-entry named-place/address index and GraphHopper car/foot/bike graphs. Way search locations are representative coordinates, not claimed entrances. No public geocoding, route service, paid credential or device location was used to build the data.

`python3 scripts/maps/test-region.py` passes against the actual local gateway and GraphHopper process. Recorded public-coordinate routes are drive 615.739 m / 62.155 s, walk 307.524 m / 223.650 s, bicycle 341.353 m / 147.332 s, with real nonempty geometry/instructions. Search/detail, no-results, missing-place, exact stored tile bytes, outside-region rejection and unsupported transit are checked. Evidence and source/tool hashes: `test-results/maps-regional-development/backend.json`. These are local backend results, not Android or navigation acceptance.

The loopback gateway binds port 47850, routing 47851, and GraphHopper administration 47852. It suppresses request logging, limits queries/response sizes, uses parameterized search SQL, permits only known local Host values and does not proxy renderer-selected destinations. Queries/coordinates remain on the development machine. Production needs an owned TLS gateway, service operations and an appropriate region deployment; the existing local service is not an internet deployment.

## App behavior

Set explicit build configuration `VITE_MAPS_BASE_URL=https://OWNED_GATEWAY` to enable a configured provider. For debug Android only, `http://10.0.2.2:47850` is accepted after reading native `BuildConfig.DEBUG` through `DailyApps.surfaceInfo`. Release Android rejects HTTP even if the environment variable was supplied. Debug Android uses a fixed-endpoint native `AlphaMapsTransport` GET bridge and a custom MapLibre tile protocol, preserving the host WebView’s prohibition on mixed content. Native HTTP checks endpoint paths, forbids redirects, sends no credentials, bounds worker/queue counts and decompressed responses, and disconnects cancelled calls. Gzip MBTiles responses are decompressed natively before returning tile bytes. A browser Vite development server may use `http://127.0.0.1:47850`. No discovery from chat, arbitrary localStorage URLs or public-service fallback occurs.

MapLibre 6.11.2 renders local vector data inside the reference map plane, retaining the surrounding Alpha UI. No third-party style, glyph, sprite, search or route endpoints are used. Attribution remains visible. The initial rendering has geographic land/water/parks/buildings/roads and a selected-place marker; street/place labels use a bundled Public Sans font without remote glyph calls. Viewport gestures are real MapLibre gestures.

Search is limited to regional named objects/addresses. Directions accept a manual coordinate origin or explicit native location. Real mode changes fetch a fresh route; edited origins clear the previous route immediately. Unsupported transit and outside-region endpoints report errors without invented routes or ETAs. Actual routing duration is marked as having no live traffic.

Foreground navigation uses the existing native location plugin, rejects fixes too approximate for guidance, and reports off-route state. It does not move the user with a timer or silently recalculate/send location. Stop/leave cancels the owned watch. Voice guidance, route sharing, background navigation and scheduled transit remain unavailable. Offline tile caching is not represented as offline search/routing; regional-service interruption is an error.

## Reproduction

1. Run `python3 scripts/maps/prepare-region.py` (Java 21, bounded 1 GiB tile JVM, two worker threads).
2. Install PyOsmium 4.1.1 in an isolated Python environment; run `scripts/maps/index-region.py`. The current Mac required a command-scoped `DYLD_LIBRARY_PATH=/opt/homebrew/opt/expat/lib` for its Homebrew Python ABI. Packages were installed into the owned `~/.local/share/alphaphone-maps/python312` directory, not globally.
3. From the data directory run `java -Xmx512m -jar graphhopper.jar server /ABSOLUTE_REPO/scripts/maps/graphhopper.yml`.
4. Run `python3 scripts/maps/serve-region.py`, then `python3 scripts/maps/test-region.py`.
5. For rendered checks start a dedicated `VITE_MAPS_BASE_URL=http://127.0.0.1:47850 npm run dev -- --port 5194 --strictPort`, then run `scripts/maps/test-renderer.mjs` with `ALPHA_BROWSER_MODULES` pointing to the existing Playwright installation.

## Connection and permission recovery (source ready)

A failed configured initialization now tells the user to submit a search to retry. The search explicitly retries the existing configured endpoint, shares any pending initialization, and cancels the intended search when the user edits, backs out or leaves. It never polls, discovers a replacement endpoint, or restarts navigation. `scripts/maps/test-recovery-renderer.mjs` passes Chromium connection-failure injection followed by recovery against the actual regional provider, including clearing a previous route on request failure. Evidence: `test-results/maps-regional-development/recovery-renderer.json`. Intercepted browser failures are not native outage proof.

Two additional native methods are gated separately: `deniedLocationAllowsManualOriginAndExplicitPermissionRetry` (`mapsPermission=1`) and `configuredGatewayFailureRecoversOnlyAfterExplicitRetry` (`mapsOutage=1`). Run `scripts/maps/test-native-recovery.mjs permission|outage APP.apk MATCHING_TEST.apk OUTPUT` with an explicit emulator serial. Permission mode uses the actual Android deny/allow-while-in-use buttons, manual-coordinate fallback, and a public Monaco GPS fixture; it restores prior coarse/fine grants and user-set/user-fixed flags. It refuses fixed or one-time permission states. Outage mode additionally requires `ALPHA_MAPS_GATEWAY_PID`; it verifies owner, command, repository working directory and port47850 listener, then briefly pauses/resumes only that process to produce a real native request timeout. GraphHopper and global networking are untouched. Each pause is bounded to25 seconds and SIGCONT is sent on normal/error/interruption cleanup. This tests unresponsiveness, not a physical loss of network connectivity. Both native recovery methods await execution on the next matching APK pair.
