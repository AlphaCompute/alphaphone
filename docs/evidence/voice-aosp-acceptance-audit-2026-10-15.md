## Event adapter validation

The native adapter admits only the `voice-transcript` stream after owner enrollment, caps admission to one voice feed per surface, and uses the existing lifecycle cancellation handles. A separate bounded feed thread leaves request workers available for ASR and cancellation. No credential is sent to the renderer. The renderer filters subscription identity; the protocol fences session/generation changes; the existing live-ASR parser additionally filters utterance/session identity and deduplicates final results. Feed failure leaves the existing HTTP final-result path available, without automatic replay or resubscription.

Five new host tests pass for foreign/non-voice events, terminal frames, cancellation before listener registration, cancellation during native admission, rejection cleanup, and protocol session replacement/disconnect. The existing 30 live-voice/assistant/segment tests pass. These checks do not establish real native IPC execution or physical speech acceptance. Hosted full verification and both Android variants are required before merging.
