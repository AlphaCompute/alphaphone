# Alpha Compute phone · powered by elizaOS

Interactive prototype of an agentic Android phone (Pixel 11 Pro, 412×915 dp), in Alpha Compute's brand.

Live: https://alpha-phone-prototype.pages.dev

## Folders

| Folder | What's in it |
|---|---|
| `prototype/` | The standalone site, exactly as deployed. Serve it locally: `cd prototype && python3 -m http.server 8000`, then open http://localhost:8000. Opening index.html directly from disk won't load it, because the browser blocks local file loads. |
| `design-canvas/` | The Claude Design canvas files: `Main.dc.html` (interactive prototype), `Approaches.dc.html` (three shell directions), `IA.dc.html` (consolidation map) and `canvas.json`. Their `/_blob/…` image and font URLs only resolve inside the canvas artifact. |
| `source/os/` | Editable source. `shell.html` + `shell.js` hold the shell (boot, lock, home, shade, chat, voice). There is one `modules/<app>.{html,js}` pair per app. `SPEC.md` holds the shared UI rules, and `img.json` maps images to canvas asset URLs. Build with `python3 build.py`, which writes `out/Main.dc.html` and `../site/dist`. |
| `source/site/` | Standalone site builder (`build.py`) and the small renderer (`dc-lite.js`). |
| `images/webp/` | The 42 photos used in the prototype, in WebP. |
| `images/originals-codex/` | Full-resolution PNG originals generated by Codex. `images/prompts.json` has the prompt for each one. |
| `brand/` | Alpha Compute lockup (`logo.svg`), the mark (`logo-mark.svg`) and Denton Light (`denton-300.woff2`, from alphacompute.ai). Public Sans loads from Google Fonts. |
| `screens/light`, `screens/dark` | Screenshots of all 68 screens and states, at 2× (824×1830). |
| `video/` | `alpha-phone-walkthrough.mp4`, the narrated walkthrough. It also holds `scenes.json` (captions and script), `narration/` (one voice clip per scene) and `tools/` (the recorder and compositor). The TTS scripts read the OpenRouter key from the `ORK` environment variable, and no key is stored here. |

## Image keys

- `p01`–`p32`: photo library.
- `cam_park`, `cam_selfie`, `cam_poster`: camera viewfinder.
- `msg0`–`msg3`: photos in Messages.
- `news`, `enclave`, `nopa`: browser page heroes.

## Type

- Display: Denton Light 300.
- UI: Public Sans.
- The α glyph falls back to Fraunces Italic, because Denton has no Greek α.
- Accent: #0000FF.
